# Tide, remembered

- Repository: https://github.com/aeiouvcode/ukiyo-tide
- Live: https://aeiouvcode.github.io/ukiyo-tide/

## Inspiration

Brief (2026-09-22): "Draw ukiyo-e with JavaScript alone." Sent with an X reference (yoshifujidesign) showing someone else's run at the same brief. Edo-period ukiyo-e woodblock prints, in particular the great-wave composition, are the artistic reference.

## References

- yoshifujidesign X post (2026-09-22): the competing take on the same brief. Exact URL in chat history.

## Findings

- The owner rejected the first still: "Make it animated and fix this, it is fake" - the wave crest read like a rake. Rebuilt animated with a foam shelf, drifting water and bobbing boats.
- The standing design agent's first pass (2026-09-23) replaced the hard wave cut and boxy UI with a rock headland and leaning pine.

## Technical decisions

- Canvas 2D generative print in about 12 KB, no images or libraries: paper grain, bokashi sky, plate-by-plate print reveal, touch water for ripples, seeded "new print" editions.
